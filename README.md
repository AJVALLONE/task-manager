# Task Manager

A Kanban-style task management board built entirely in vanilla JavaScript — no frameworks, no dependencies.

## Features
- Three columns: Backlog, In Progress, Done
- Native HTML5 drag-and-drop between columns
- Add tasks with title, optional note, and priority level (High / Medium / Low)
- Delete tasks with a single click
- Full state persistence via localStorage — nothing lost on refresh
- Keyboard shortcuts: Enter to submit, Escape to cancel
- Pre-loaded with sample tasks on first visit

## Tech Stack
HTML5 · CSS3 · JavaScript (ES6+) · LocalStorage · HTML5 Drag and Drop API
